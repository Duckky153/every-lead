How it works

Every lead gets worked

Dakshit Raj · November 2026 · built with Claude Code and Jev

A common way to work a lead list is to fix the broken leads first, then call the rest. Every Lead works the other way. The good leads don't wait, and the broken ones don't get thrown away.

It runs on one made-up day of 100 small-business insurance leads. One AI model reads what each person wrote. Plain code makes every decision.

Three groups

Every lead goes into one of three groups. None are dropped.

Go now. Call them, most urgent first. 81 of the 100 leads go here.

Fix first. Only the leads a call can't work yet: the phone doesn't work, there's no way to reach them, or it's the same business that came in earlier. 13 go here.

Check first. A person reads it before anyone acts. It looks like spam, it tries to give orders to a computer, or the model was unsure about something risky. 6 go here.

Say a roofer fills in the form, and the headcount on the form doesn't match the note. That's not a reason to make them wait. It's a question for the first call, so it goes with the lead to Go now. 21 leads carry a question like that.

One model step

Most of a lead is form fields, and code can check those. A phone number has ten digits or it doesn't.

What code can't check is what the person wrote. If the form says Restaurant and the note says "two-truck electrical shop," only a reader notices.

So one step uses a model. Jev, TypeSafe's model, reads the note and answers seven fixed questions:

  • What does the business do?
  • Who wrote it?
  • Do they ask a coverage question?
  • When do they need it?
  • How many people work there?
  • Is it spam?
  • Does it try to give orders to a computer?

Each answer is a label and a number. Jev never writes text, and it never decides. Code checks every answer before using it. If a reply comes back broken, the lead goes to a person, and the form checks still run.

When Jev is unsure. Each question has a safe default. Unsure about something risky? A person reads it. Unsure about a coverage question? A licensed agent answers it. Unsure about spam? It counts as not spam, so a real lead isn't set aside. Unsure about who wrote it, the headcount or the timing? It's ignored, and the first call checks it.

Fix it, don't drop it

A lead in Fix first gets four things.

One person responsible. The customer, a teammate or a licensed agent. Never "someone".

The exact fix. Something a new teammate could do without asking anyone. "Email them and ask for the best number to reach them." "Merge this into the earlier lead, so nobody calls them twice."

A message, never sent. When the customer has to send something, a message is drafted that asks for only that one thing.

A second check. When the answer comes back, the same check runs again. If it passes, the lead moves on.

Every lead also shows its steps: when it came in, what Jev read, which checks failed, and what it's waiting for. Each step is labeled by who did it (MODEL, CODE or PERSON, and YOUR CLICK for your own clicks), so you can see exactly where the model was involved. Nothing in Every Lead gives insurance advice or a price.

How we know it works

The leads are made up, and 40 of them were given problems on purpose. That makes it possible to score the result. It also makes it easy to fool yourself. So the scoring has guards.

Frozen first. The right answers and rules were frozen before Jev read the scored leads. A test fails if they change without a logged reason. One sorting rule changed after the run. It's logged, and the page shows the score both ways.

Tuned elsewhere. The questions were tried on 30 separate practice leads first. None needed changing.

A second reader. A different AI labeled 20 leads without seeing the answers, and agreed on every one. That shows the rules are clear, not that the answers are right.

A yardstick. Simple keyword rules, with no model, answered the same questions.

Every miss shown. The page lists every miss and every false alarm, with how sure Jev was.

The one miss was a relative writing for the business. Jev was unsure, and an unsure answer there is ignored, because every first call starts by asking who decides. Jev's weak spot was call notes, where a teammate writes about the caller ("Spoke with Dale Harmon, the owner"). It often couldn't tell that the caller was the owner.

What's next

Today it runs on one made-up day, and nothing is sent. Jev's answers are saved (one run, plus re-reads of 13 leads after small text fixes), and only a person closes a lead. Nobody uses it yet.

To make it real, the same steps would start when a real lead comes in, and the next step would show up in the tools the team already uses. The scoring would run the same way on real leads. A step would move from a person to the system only when the numbers say it's ready.
